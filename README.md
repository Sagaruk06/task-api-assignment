# Task Manager API

A simple Task Manager REST API built with Node.js and Express.

This project was completed as a backend take-home assignment. The main focus was testing an existing API, finding and fixing a bug, and adding a task assignment feature.

## Features

- Create tasks
- Get all tasks
- Get tasks by status
- Update tasks
- Delete tasks
- Complete tasks
- Get task statistics
- Paginate tasks
- Assign tasks to an assignee

## Tech Used

- Node.js
- Express.js
- Jest
- Supertest
- UUID

## Getting Started

Clone the repository and go to the project folder:

```bash
cd task-api
```
